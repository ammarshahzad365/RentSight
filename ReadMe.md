# RentSight – Short-Term Rental Analytics & Occupancy Tracker

RentSight is a data-driven application for analyzing Airbnb and other short-term rental (STR) listings.  
It tracks location, price, amenities, room type, and ratings, while estimating occupancy rates through calendar monitoring and review-based methods.  
Designed for hosts, investors, and researchers to uncover market trends, optimize pricing, and improve performance.
